# Design principles

Principles the group set for an adaptive gaming platform, as recorded after the session.

## Product

- Keep each game simple. Ship one game at a time.
- Keep games casual, interesting and cultural.
- Slow is smooth, smooth is fast: go slow on architecture, fast on delivering games.
- Headless games: API first, AI first.
- Share everywhere.

## Platform

- Self-serve.
- Resilience mechanisms informed by the Cynefin framework.
- Self-organizing. The group framed the ideal as autopoietic: a system that produces itself (Maturana and Varela, *Autopoiesis and Cognition*, 1972/1980).
- Game creators, players, and parents or mentors are all actors on the platform.
- Dashboards and observability built in.

## Values

- Ethics by design.
- Trust and responsibility by design.
- Educate, educate, educate.
- Creative Commons and open-source thinking.
