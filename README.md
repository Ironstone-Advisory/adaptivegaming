# AdaptiveGaming

**A courtesy archive of a September 2024 group exercise: eleven people building a full IP package with AI, from a single game, in one day.**

AdaptiveGaming is not a product and not owned by anyone in particular. It is a record of a working session, kept public on purpose as **prior art** and as an example of how fast AI lets a group go from a toy to a platform concept.

> Ironstone Advisory hosts this archive as a courtesy to the participants. **Ironstone Advisory does not own it.** The work is shared under Creative Commons Attribution 4.0 (CC BY 4.0) and belongs to its contributors.

## What happened

On September 15, 2024, Rob Tyrie and ten partners ran an experiment: start with one small piece of working software and see how far a group plus AI could take it in a day.

1. A simple concentration-style card game was generated as a standalone React component. It worked after a few prompts.
2. The group observed that the same game could be re-themed into a thousand variants by adding one transformation layer.
3. Documentation was generated from the software: requirements, a design doc and a config file detailed enough to regenerate variants on demand.
4. A press release was written for a notional company. The name "adaptive gaming" came a little later.
5. A platform architecture diagram was drawn live, with each participant adding components around the table.
6. The whole concept was written up in the form of a patent application: *Blockchain-Enabled Adaptive Educational Game Factory Platform with Integrated Economy and Ethical AI*.

The tagline that came out of it: **adaptive games = infinite(casual(games))**.

## Why it is public

- **Prior art.** Publishing the concept, dated, under CC BY 4.0 means nobody can later lock it up with a patent.
- **A worked example.** It shows a repeatable method: software first, then documentation generated from the software, then the business and IP wrapper, all in hours.
- **Credit.** Everyone who was in the room is named below.
